# HYPER·CAR — NOCTIS HC-24 Le Mans Hypercar

An interactive, real-time 3D Le Mans hypercar showcase built with three.js, running entirely in the browser.

**Live demo:** https://j01741520-coder.github.io/hypercar/

## Controls

| Key | Action |
| --- | --- |
| `1`–`7` | Camera presets: hero / rear / side / front / top / cockpit / suspension cutaway |
| `0` | Reset camera |
| `N` | Switch studio / night track |
| `X` | X-ray view |
| `A` | Aero flow lines |
| `L` | Lights |
| `C` | Cycle liveries |
| Hold `B` | Brake |

## Files

- `index.html` / `hypercar.html` — the self-contained page (identical)
- `src/` — source modules and template; `build.py` bundles them into the HTML
